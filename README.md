🗳️ DeskDecide

DeskDecide is a role-based voting system that includes two access levels: Organizer and Voter. Organizers can manage candidates and categories, while voters can securely cast their votes through a structured voting interface.

Key Features:

Separate Organizer and Voter access

Candidate and category management

Voting functionality

Structured and controlled user flow

This project demonstrates user role management, system logic separation, and database-driven voting mechanisms.
